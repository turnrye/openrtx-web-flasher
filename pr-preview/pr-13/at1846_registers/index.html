AT1846S register table

0x04
Section titled “0x04”
bit function notes
0 clock mode (frequency range) 0 = 24~28MHz
1 = 12~14MHz
0x08
Section titled “0x08”
bit function notes
14 LDO bypass 1 = bypass all the AT1846S internal LDOs. Must be 0 in VHF band.
0x09
Section titled “0x09”
bit function notes
9:7 LDO output voltage 100=2.20V
101=2.40V
110=2.80V
111=3.30V
0x0A
Section titled “0x0A”
bit function notes
5:0 PA bias voltage 000000: 1.01V
000001:1.05V
000010:1.09V
000100: 1.18V
001000: 1.34V
010000: 1.68V
100000: 2.45V
111111: 3.13V
0x0F
Section titled “0x0F”
bit function notes
1:0 band select 00 = 400~520MHz
10 = 200~260MHz
11 = 134~174MHz
0x1F
Section titled “0x1F”
bit function notes
15:14 GPIO7 mode 00 = hi-z
01 = vox
10 = low
11 = high
13:12 GPIO6 mode 00 = hi-z
01 = squelch or squelch & CTC/DCS when sq_out_sel = 1
10 = low
11 = high
11:10 GPIO5 mode 00 = hi-z
01 = txon_rf
10 = low
11 = high
9:8 GPIO4 mode 00 = hi-z
01 = rxon_rf
10 = low
11 = high
7:6 GPIO3 mode 00 = hi-z
01 = sdo
10 = low
11 = high
5:4 GPIO2 mode 00 = hi-z
01 = int
10 = low
11 = high
3:2 GPIO1 mode 00 = hi-z
01 = code_out/code_in
10 = low
11 = high
1:0 GPIO0 mode 00 = hi-z
01 = css_out/css_in/css_cmp
10 = low
11 = high
0x29
Section titled “0x29”
bit function notes
13:0 frequency upper part [29:16]
0x2A
Section titled “0x2A”
bit function notes
15:0 frequency lower part [15:0]
0x2B
Section titled “0x2B”
bit function notes
15:0 reference clock frequency in kHz 12~14MHz: crystal freq (MHz) × 1000
24~28MHz: (crystal freq (MHz) / 2) × 1000
0x2C
Section titled “0x2C”
bit function notes
15:0 ADC clock frequency in kHz 12~14MHz: (crystal freq (MHz) / 2) × 1000
24~28MHz: (crystal freq (MHz) / 4) × 1000
0x2D
Section titled “0x2D”
bit function notes
9 css_cmp interrupt enable
8 rxon_rf interrupt enable
7 txon_rf interrupt enable
6 dtmf_idle interrupt enable
5 ctcss phase shift detect int. enable
4 idle state time out int. enable
3 rxon_rf timeout interrupt enable
2 sq interrupt enable
1 txon_rf time out interrupt enable
0 vox interrupt enable
0x30
Section titled “0x30”
bit function notes
13:12 channel mode 11 = 25khz channel mode
00 = 12.5khz channel mode
10,01 = reserved
11 enable tail noise elimination
9:8 st mode 11 = reserved
10 = txon_rf & rxon_rf auto
01 = rxon_rf auto, txon_rf manual
00 = txon_rf & rxon_rf manual
6 tx enable
5 rx enable
4 on-chip VOX enable
3 on-chip squelch enable
2 chip power enable 1 = chip enabled
0 = deep sleep
0x35
Section titled “0x35”
bit function notes
15:0 DTMF tone freq 1 register_value = freq (kHz) × 2^12
0x36
Section titled “0x36”
bit function notes
15:0 DTMF tone freq 2 register_value = freq (kHz) × 2^12
0x3C
Section titled “0x3C”
bit function notes
15:14 voice selection 00 = Tx voice signal from MIC
01 = Tx inner sine tone set by tone2
10 = Tx code from GPIO1 code_in (gpio1<1:0> must be
set to 01)
11 = not Tx any signal
0x41
Section titled “0x41”
bit function notes
15:0 VOX open threshold
0x42
Section titled “0x42”
bit function notes
15:0 VOX close threshold
0x43
Section titled “0x43”
bit function notes
12:6 transmitter FM deviation CTC/DCS and voice FM deviation
5:0 transmitter FM deviation CTC/DCS only FM deviation
0x44
Section titled “0x44”
bit function notes
7:4 RX voice range - volume 1 (0000)-15dB~(1111)0dB, step 1dB
3:0 RX voice range - volume 2 (0000)-15dB~(1111)0dB, step 1dB
0x45
Section titled “0x45”
bit function notes
15:14 tail elimination CTCSS phase shift 00 = 120 degree shift
01 = 180 degree shift
10 = 240 degree shift
11 = reserved
11 enable CDCSS detection
10 enable CTC/DCS detection
7 enable CDCSS inverse code detect
4 CDCSS code selection 1 = 24 bit code
0 = 23 bit code
3 CTCSS code selection 1 = ctcss_cmp/cdcss_cmp out via gpio
0 = ctcss/cdcss sdo out via gpio
2:0 CTC/DCS mode selection 000 = disable
001 = inner ctcss en
010 = inner cdcss en
101 = outer ctcss en
110 = outer cdcss en
others = disable
0x48
Section titled “0x48”
bit function notes
9:0 squelch open threshold
0x49
Section titled “0x49”
bit function notes
9:0 squelch close threshold
0x4A
Section titled “0x4A”
bit function notes
15:0 CTCSS frequency register_value = CTCSS freq (kHz) × 2^16 (e.g. 97.4 Hz → 0.0974 × 2^16 = 6383).
It must be set to 134.4Hz when use standard cdcss mode.
When use ctcss/cdcss, this register must be set both in rx and tx state
0x4B
Section titled “0x4B”
bit function notes
7:0 CDCSS code [23:16] MSB sent first
0x4C
Section titled “0x4C”
bit function notes
15:0 CDCSS code [15:0]
0x54
Section titled “0x54”
bit function notes
7 squelch output selection If 1, the output gpio6 is sq & css_cmp, else, the output gpio is sq only.
0x58
Section titled “0x58”
bit function notes
9:7 RX CTC/DCS hi-pass filter bandwidth 000(narrow)~111(wide)
6 RX CTC/DCS hi-pass filter bypass 1 = bypass
0 = normal
5:4 voice low-pass filter bypass 11 = bypass
0 = normal
3 pre/de-emphasis bypass 1 = bypass
0 = normal
2 CTC/DCS low-pass filter bypass 1 = bypass
0 = normal
1:0 voice hi-pass filter bypass 11 = bypass
0 = normal
0x5C
Section titled “0x5C”
bit function notes
12 DTMF idle
10 RX enabled
9 TX enabled
7 CTCSS phase shift detected
2 CTC/DCS compared
1 squelch status
0 VOX status
0x5F
Section titled “0x5F”
bit function notes
9:0 RSSI level read only register, unit 1/8dB
0x60
Section titled “0x60”
bit function notes
14:0 voice signal strength indication read only register, unit mV
0x63
Section titled “0x63”
bit function notes
9:8 DTMF mode 11 = transmit or receive Dtmf single tone2
01 =transmit or receive Dtmf dual tone1+tone2
others = disable
7:4 DTMF time 1 Time interval for dual tone transmission. Time = register_value × 5ms
3:0 DTMF time 2 Time interval for DTMF idle state. Time = register_value × 5ms
0x66
Section titled “0x66”
bit function notes
15:8 DTMF C0 01100001 12.8MHz and 25.6MHz
01100001 13MHz and 26MHz
7:0 DTMF C1 01011011 12.8MHz and 25.6MHz
01011110 13MHz and 26MHz
0x67
Section titled “0x67”
bit function notes
15:8 DTMF C2 01010011 12.8MHz and 25.6MHz
01010111 13MHz and 26MHz
7:0 DTMF C3 01001011 12.8MHz and 25.6MHz
01001011 13MHz and 26MHz
0x68
Section titled “0x68”
bit function notes
15:8 DTMF C4 00101100 12.8MHz and 25.6MHz
00110001 13MHz and 26MHz
7:0 DTMF C5 00011110 12.8MHz and 25.6MHz
00011110 13MHz and 26MHz
0x69
Section titled “0x69”
bit function notes
15:8 DTMF C6 00001010 12.8MHz and 25.6MHz
00001111 13MHz and 26MHz
7:0 DTMF C7 11110110 12.8MHz and 25.6MHz
11111011 13MHz and 26MHz
0x6C
Section titled “0x6C”
bit function notes
10:5 DTMF index [5:0] [5:3] tone1 detect index
[2:0] tone2 detect index, will be used in single tone mode
4 DTMF code not valid
3:0 DTMF code [3:0]
