Ailunce HD1

Specifications

Section titled “Specifications”
  • MCU: NXP MK22FN512VLL12
  • Baseband: Hongrui HR_C6000
  • Display: 160x128 color TFT
  • Frequency ranges
    • VHF: 136.0000-174.0000
    • UHF: 400.0000-480.0000

Hardware Configuration

Section titled “Hardware Configuration”

The Ailunce HD1 is very similar to the Radioddity GD77 in its hardware configuration, schematics for this radio are public domain and can be accessed here.

Flashing

Section titled “Flashing”

Support for flashing the Ailunce HD1 is implemented in this radio_tool fork, to be merged upstream. You can flash a raw binary as produced by objcopy, the bootloader will write it at offset 0x4000.

M17 Path

Section titled “M17 Path”

  • MCU to RF:

    1. Generation of baseband signal via PWM modulator on pin 53 (RING/1750Hz) -> same mechanism of MD380
    2. Remove C51 and C389 to extend the signal bandwidth towards the AT1846S (probably not needed, testing required)

  • RF to MCU:

    1. Connect pin 1 of U104 either to MCU pin 16 or pin 20 (ADC inputs) for sampling of incoming baseband signal, after amplification stage
    2. Remove C370? -> extend bandwidth of incoming signal down to DC level, should have no impact on DMR

  • Mic to MCU:

    1. Usage of VOX signal
    2. Remove C356, Q309, C355 -> removal of peak detector circuit, as in MD380
    3. Keep R363 and add 100k resistor towards 3v3 -> add DC bias of VDD/2 to mic signal

  • MCU to spk:

    1. Use HR_C6000 sound playback functionality, it should not be painful.

Hardware Version Discovery

Section titled “Hardware Version Discovery”

On startup the application image calls a function at 0x3000 with its model string, which triggers a reset if it doesn’t match. the models are either IHDHD1GPS for the GPS model, or IHDUV8580 for the non-GPS model

CHORD U306

Section titled “CHORD U306”

This chip is the voice synthesizer from the baofeng radio

86 -> “Channel Mode”
85 -> “Frequency Mode”
60 -> “Zero”
62 -> “Two”
…
69 -> “Nine”
? -> “Cancel”
