What a backup keeps

Before it flashes, the flasher offers to back the radio up: a copy of what is on it, to go back to if you need to. For most radios that copy is not whole yet. This page says, radio by radio, what it leaves out and what that would cost you, so you can decide before you flash. It is written from the same record the flasher's backup step reads.

Backed up whole

Module 17 and Retevis C62 / C2: a backup holds everything the radio keeps, and the flasher can write it back.

Not whole, worst first

Worst first means what is lost for good, and how soon flashing loses it. Each item is a memory the backup does not hold, what that costs you, and whether it can be saved some other way.

Connect Systems CS7000-M17

  • Not saved: memory chip (W25Q128). The factory calibration, which is not published. OpenRTX erases 0x8000 to 0xBFFF of this chip for its own settings the first time it starts. Saving it needs a dumper, a small reader loaded onto the radio for the occasion, which is not built yet.

Connect Systems CS7000-M17 Plus

  • Saved in part: program memory (STM32H743). The bootloader and DMR firmware as this radio had them. Flashing OpenRTX leaves both in place, and Connect Systems publishes both. Saving it needs a dumper, a small reader loaded onto the radio for the occasion, which is not built yet.
  • Not saved: memory chip. The factory calibration, which is not published. OpenRTX erases 0x1000000 to 0x1003FFF of this chip for its own settings the first time it starts. Saving it needs a dumper, a small reader loaded onto the radio for the occasion, which is not built yet.

Radtel RT-950 Pro

  • Not saved: program memory. The original firmware as this radio had it. Flashing replaces it; Radtel publishes firmware files. Saving it needs a dumper, a small reader loaded onto the radio for the occasion, which is not built yet.
  • Saved in part: memory chip. Everything above 64 KiB, which is 63/64 of the chip: fonts, the start-up picture and whatever else Radtel keeps there. Saving it needs a dumper, a small reader loaded onto the radio for the occasion, which is not built yet.

A radio that already runs OpenRTX cannot be backed up this way: the read is answered by the manufacturer's firmware, and OpenRTX has replaced it. OpenRTX has no backup command of its own yet.

Tytera MD-9600

  • Saved in part: program memory (STM32F405). The original firmware as this radio had it (the other 960 KB). Flashing replaces it, and the only way back is the manufacturer's firmware file for this model and board. Saving it needs a dumper, a small reader loaded onto the radio for the occasion, which is not built yet.
  • Not saved: the memory chip's security registers. The factory calibration in the form it is stored, which is not published. OpenRTX reads its calibration from these registers and does not write them. Saving it needs a dumper, a small reader loaded onto the radio for the occasion, which is not built yet.

A radio that already runs OpenRTX cannot be backed up this way: the read is answered by the manufacturer's firmware, and OpenRTX has replaced it. OpenRTX has no backup command of its own yet.
